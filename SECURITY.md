# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. On the GitHub repository, open the
**Security and quality** tab and select **Report a vulnerability**. Include the affected
version or commit, impact, prerequisites, and reproducible steps or a proof of concept.
Avoid including real credentials or customer data in the report.

If private reporting is unavailable, open an issue asking for a private contact without
disclosing the vulnerability or sensitive details. Do not publish an exploit or open a
public issue or pull request containing the vulnerability before coordinating with the
maintainers.

We review reports against the current default branch. Reports affecting older versions
are welcome; include the version so maintainers can assess its status. Maintainers will
coordinate investigation and disclosure with the reporter through the private report.
