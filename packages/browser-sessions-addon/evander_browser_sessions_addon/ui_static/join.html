Share your application tab with your agent

  1. Install the Evander Browser Assistance Chrome extension supplied by your administrator. Download the extension ZIP.
  2. Copy this invitation link, then open the application tab you want help with.
  3. Click the extension, paste the link, and review the sharing request.

Sharing starts in observation mode. You can allow interaction, pause, or end sharing from the extension panel.

This invitation does not grant access to an Evander-hosted browser. Hosted sessions require control-plane sign-in.
